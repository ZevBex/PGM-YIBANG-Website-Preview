# V9.42.14 Lightweight Update — Homepage Banner

This update contains only the homepage HTML file and the new tablet-specific banner stylesheet.

## Install
1. Copy `index.html` to the website root, replacing the existing file.
2. Copy `assets/css/v9.42.14-tablet-banner-centering.css` to the same path in the website.
3. Keep all other files and folders unchanged.
4. After deployment, hard-refresh the website (`Ctrl + F5`).

The CSS is loaded only on the homepage. It centers the hero poster and video between 801px and 1180px viewport widths.
