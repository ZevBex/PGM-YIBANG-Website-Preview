# V9.42.10 — Navigation Color + Arrow Only

## Base
V9.42.9 Full Mega Menu Panels Clickable.

## Change
- Removed the horizontal underline/bottom line from navigation hover, open, and current-page states.
- Top-level navigation text changes to the existing PGM/YIBANG gold on hover and on the current page.
- Dropdown navigation text changes to gold on hover, while open, and when its group contains the current page.
- Dropdown carets rotate upward on hover, while open, and when the dropdown group is the current page.
- The visual state is now communicated by text color and caret direction only.
- Kept a subtle keyboard-focus outline for accessibility; it is not a persistent underline.

## Preserved
- V9.42.9 full-panel click targets for the left introduction and right feature card.
- Existing destinations, menu alignment, dropdown layout, labels, descriptions and mobile accordion behavior.
- Header/footer branding, hero media and page content.

## Scope
Only the shared navigation interaction stylesheet and its cache-busting references were updated.
