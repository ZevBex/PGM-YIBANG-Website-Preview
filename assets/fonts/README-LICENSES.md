# Self-hosted website fonts

The website uses locally hosted, subsetted WOFF2 fonts to keep typography consistent and avoid relying on external font CDNs.

- Inter / Inter Display: SIL Open Font License 1.1. The Inter package copyright and license notice is included in `COPYRIGHT-Inter.txt`.
- EB Garamond: SIL Open Font License 1.1. The copyright and license notice is included in `COPYRIGHT-EB-Garamond.txt`.
- Noto Sans CJK SC: SIL Open Font License 1.1. The Noto CJK copyright and license notice is included in `COPYRIGHT-Noto-Sans-CJK.txt`.

The distributed WOFF2 files are subsetted for the text used by this website and converted for web embedding. The fonts are bundled with the website, not sold as standalone font files. Documents or images created using the fonts are not subject to the font license.
