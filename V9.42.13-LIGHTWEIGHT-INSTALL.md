# V9.42.13 Lightweight Update — Installation

This package contains only the 23 HTML pages that use the shared navigation, plus the updated navigation CSS and JavaScript.

## Replace these files
1. Copy all included `.html` files into the website root, replacing the matching files.
2. Copy `assets/css/v9.42.7-navigation-hover-contrast.css` to the same path in the website, replacing the old file.
3. Copy `assets/js/navigation-v98.js` to the same path in the website, replacing the old file.
4. Keep all other website folders and files unchanged.
5. After publishing, open the site and hard-refresh with `Ctrl + F5`.

Both the CSS and navigation JavaScript references use the `9.42.13` cache version so browsers request the updated files.
