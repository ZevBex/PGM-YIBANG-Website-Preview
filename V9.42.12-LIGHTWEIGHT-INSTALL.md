# V9.42.12 Lightweight Update

This update contains only the shared navigation stylesheet, the 23 HTML pages that reference it, and this install note.

## Install
1. Copy the 23 included HTML files to the website root, replacing the matching files.
2. Copy `assets/css/v9.42.7-navigation-hover-contrast.css` to the same path in the website, replacing the old CSS file.
3. Keep all other folders and files unchanged.
4. After deployment, hard-refresh the browser (`Ctrl + F5`).

The HTML pages reference stylesheet version `v9.42.12` to avoid using a cached older CSS file.
