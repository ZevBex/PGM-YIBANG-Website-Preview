# V9.5 UI consistency fixes

- Unified the header CTA typography, height, spacing and responsive sizing across all 20 pages.
- Unified header geometry, logo sizing, navigation typography and mobile navigation behavior.
- Standardized the footer layout and typography across homepage and inner pages.
- Added one consistent Back to Top control to every page, including the homepage.
- Made navigation dropdowns exclusive: opening one closes the others.
- Disabled legacy hover/focus rules that could display several dropdown panels simultaneously.
- Anchored each dropdown panel to its own menu item to prevent overlap.
- Added Escape-to-close, outside-click close and aria-expanded state updates.
- Added a tablet breakpoint so navigation switches to hamburger before desktop items become crowded.

Existing products, videos, enquiry flows, bilingual content and partnership sections are retained.
