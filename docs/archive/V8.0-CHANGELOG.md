# V8.0 — Future Golf Technology Homepage Prototype

## Design direction
- Introduces a premium technology-led visual system: midnight navy, near-black, restrained champagne gold and limited technical cyan.
- Replaces the traditional V7 homepage layout with a cinematic product hero, compact glass navigation, scroll progress indicator and restrained motion.
- Keeps the design premium and golf-focused rather than using an esports / neon-heavy visual language.

## Homepage sections
1. Cinematic hero with AI-generated conceptual golf driver visual.
2. Brand and capability strip, using only grounded brand / in-house capability statements.
3. PGM × YIBANG positioning: brand, development team and manufacturing partner.
4. Product ecosystem, rendered from the existing product data.
5. Interactive OEM / ODM golf club configuration concept.
6. Interactive digital factory explorer using company-provided design, process, production and QC photographs.
7. Three PGM athlete partnerships and their distinct product categories.
8. PGM 2026 brand film and Liang Wenchong CHONG Series collaboration video.
9. Project enquiry call-to-action and floating quote entry.

## Interactive behavior
- Desktop glass navigation compresses on scroll; mobile navigation remains responsive.
- Scroll progress indicator and subtle pointer parallax on the hero.
- Scroll reveal transitions, with reduced-motion support.
- Configurator options update the selected configuration summary and concept preview state.
- "Send this configuration" carries the selected brief into the existing Contact form using the existing `topic` / `product` query handling.
- "Copy brief" copies the selected configuration for the buyer.
- Factory process tabs switch the real company-provided image, stage heading and bilingual description.
- Existing bilingual EN / 简体中文 switch, product rendering, enquiry form, WhatsApp and existing inner pages are retained.

## Accuracy and asset notes
- `assets/images/hero-driver-v8.jpg` is AI-generated conceptual product artwork. It is not a photograph of an actual PGM model and is labelled as a concept visual on the homepage. Replace it with approved PGM product photography before commercial launch.
- The configurator is an interactive concept preview, not a production-ready 3D configurator. All selected options are illustrative and subject to model-specific feasibility confirmation.
- Factory explorer images are company-provided. Text distinguishes in-house design, assembly and QC functions from selected specialized processing coordinated through long-term partner factories.
- Athlete portraits use temporary official tour/profile image URLs already documented in the V7.2 project. Confirm commercial image / likeness rights or replace with PGM-authorized images before public launch.
- No uncertain platform rankings, patent totals, trademark-country counts, export-market totals or unverified factory capacity numbers are added to the new homepage.
- The 20-year PGM brand heritage statement is retained from the brand information supplied for this project.
- Both supplied Alibaba MP4 video sources are retained with native controls and no autoplay. Playback must be verified on the deployed domain.

## Scope
- V8.0 redesigns the homepage (`index.html`) and adds homepage-specific CSS / JS.
- The remaining 15 HTML pages retain their V7.2 page design and existing functionality for now. They will be brought into the V8 visual system after the homepage direction is approved.

## Deploy
1. Back up the current GitHub repository.
2. Unzip this package.
3. Upload the contents of the `PGM-YIBANG-Golf-Website-V8.0-Future-Golf-Technology/` folder to the repository root, preserving the `assets/` structure.
4. Open `index.html` to preview locally, or deploy to GitHub Pages.
5. Test desktop and mobile layouts, EN / 中文 switching, product cards, configurator, factory tabs, videos, contact form and WhatsApp.
6. Confirm player-image and product-image commercial permissions before public advertising use.
