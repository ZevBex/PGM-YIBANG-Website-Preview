# PGM × YIBANG GOLF — V9.9 Bilingual UI Fixes

## Fix 1 — Language switcher restored
- The V9.8 pages already contain a static `.language-switch` button in the navigation.
- The previous `ensureSwitcher()` returned early when it found that button, so it never attached the click handler.
- V9.9 now binds the existing button (and any additional switchers) exactly once.
- Switching language updates the page language, translated text/attributes, page metadata, active language indicator and localStorage preference.
- The existing mobile-menu close behavior is retained.

## Fix 2 — Adaptive inner-page banners
- Removed the fixed 440px desktop and 350/340px mobile height caps from standard inner-page banners.
- Standard inner banners now share a consistent minimum canvas, while their height grows naturally when headings, descriptions, CTA buttons, breadcrumbs or translated Chinese copy need more room.
- The desktop minimum is 480px, tablet minimum 430px and mobile minimum 370px.
- Removed the extra inner vertical padding from legacy V7 hero content wrappers to avoid double padding.
- The player-collaboration split hero now sizes to both its text and visual.
- The digital experience heroes are also content-led and no longer clipped by a fixed 440px height.
- Background images continue to cover the expanded banner area; text and controls remain fully visible.

- Existing bilingual content, videos, assets and responsive navigation.
