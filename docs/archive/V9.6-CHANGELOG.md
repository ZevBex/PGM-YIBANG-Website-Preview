# V9.6 — Professional Product Experience

## Global layout
- Standard inner-page banners now use one desktop height (440px), tablet/mobile sizing rules, consistent content alignment and a shared title/lead/breadcrumb rhythm.
- The immersive digital-experience heroes retain a responsive two-column desktop layout and a stacked mobile layout.
- Homepage hero remains intentionally distinct from inner-page banners.

## Bilingual system
- `data-en` / `data-zh` and `data-v9-en` / `data-v9-zh` are now applied directly on leaf text elements during language switching.
- Added missing Chinese translations for navigation, CTA labels, page hero copy, breadcrumbs and product detail interface text.
- Existing dictionary translations, page metadata, product data and enquiry logic are retained.

## Product detail experience
- Rebuilt the product detail page around a 6-image gallery with thumbnail selection, zoom lightbox, keyboard navigation and mobile swipe.
- Added structured sections for overview, model-specific specifications, OEM / ODM customization, manufacturing coordination and product enquiry.
- Product enquiry buttons automatically pass the selected product ID to the contact form.
- Driver gallery uses temporary AI-generated concept images and is clearly disclosed as non-model-specific. Other categories use category illustrations plus company-provided development / process references, also clearly labeled as non-model-specific.

## Existing features retained
- 20 HTML pages, existing navigation/footer, back-to-top, quote CTA, video embeds, brand partnership sections, product catalog, configurator, digital factory tour and RFQ builder.
