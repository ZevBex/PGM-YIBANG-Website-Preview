# PGM × YIBANG GOLF — V9.0 Intelligent Golf Manufacturing Experience

## New buyer-facing experiences
- Expanded the website from 16 to 20 HTML pages (including the 404 and privacy / thank-you utility pages).
- Added `club-configurator.html`: interactive concept configurator for product category, head finish preference, shaft preference, grip, branding and hand orientation. Selections are passed into the guided project brief.
- Added `factory-tour.html`: stage-based tour using company-provided design, development, production and QC images. In-house functions are distinguished from selected partner-factory processing. Includes the supplied PGM factory introduction video embed.
- Added `project-builder.html`: four-step guided RFQ / project brief builder covering product category, cooperation model, quantity, target market, customization and buyer contact details. The form submits to the existing FormSubmit destination.
- Added `thank-you.html` as the FormSubmit return page target; it is marked noindex and excluded from the sitemap.
- Added a Digital Experience navigation dropdown across the site and updated the homepage configurator to carry selections into the RFQ builder.
- Added V9 responsive styles, keyboard-operable controls, reduced-motion support, bilingual labels and updated privacy wording for the project-builder fields.

## Important implementation boundaries
- The RFQ builder is a guided structured form, not a live AI model and not an instant quotation engine. It sends the submitted brief to the existing FormSubmit email endpoint.
- The club configurator is an illustrative concept preview using included SVG category artwork; it is not a 3D engineering model or a promise that every selected combination is available. Final options, materials, MOQ, specifications and lead time require project confirmation.
- The factory tour uses company-provided photographs and explicitly distinguishes in-house design / assembly / QC from selected processing handled by long-term partner factories.
- The factory video is embedded from the YouTube URL documented in the V8.1 README. Playback depends on YouTube availability and browser policy.
- FormSubmit may require activation of `tracy@pgmgolf.com` before first public use. Test a real submission after deployment.
