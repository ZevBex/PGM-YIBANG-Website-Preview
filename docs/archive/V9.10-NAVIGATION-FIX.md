# V9.10 — Mega Menu Navigation Stabilization

## Root cause
The V9.5 global shell stylesheet used higher-specificity selectors for `.nav-dropdown` and `.nav-dropdown-menu` than the V9.8 navigation stylesheet. As a result, desktop mega menus inherited the legacy per-item dropdown positioning and 238–300px width limits. The wide menu panel was therefore anchored to an individual navigation item and constrained like a small dropdown.

## Fix
- Added `navigation-v910-stabilizer.css` as the final stylesheet on all 21 pages.
- Restored `position: static` on desktop `<details class="nav-dropdown">` elements so the mega panel is positioned relative to the full sticky header.
- Explicitly restored full-width centered desktop mega-menu geometry and the intended 220px intro + flexible content grid.
- Removed inherited legacy dropdown width limits, offsets, borders and backgrounds.
- Added responsive accordion styling for tablet and mobile, overriding old global-shell dropdown rules with higher-specificity selectors.
- Added safe text wrapping and panel max-height scrolling to prevent long bilingual content from distorting the menu.

## Scope
All 21 HTML pages. Existing navigation labels, destinations, bilingual data attributes, language switch behavior and page content are retained.
