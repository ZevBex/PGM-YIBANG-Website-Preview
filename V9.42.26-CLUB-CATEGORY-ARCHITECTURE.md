# V9.42.26 — Golf Club Category Architecture

## Core club categories
1. Drivers — 一号木 (`drivers`)
2. Fairway Woods — 球道木 (`fairway-woods`)
3. Hybrids — 铁木杆 (`hybrids`)
4. Irons — 铁杆 (`irons`)
5. Wedges — 挖起杆 (`wedges`)
6. Putters — 推杆 (`putters`)

## Additional product ranges
- Complete Golf Club Sets — 高尔夫全套球杆 (`sets`)
- Park Golf Clubs — 公园高尔夫球杆 (`park`)
- Junior Golf Clubs — 青少年高尔夫球杆 (`junior`)

## Implementation
- Reworked the homepage OEM / ODM module into six individual core club-type cards.
- Added two separate additional-range cards for Complete Golf Club Sets and Park Golf Clubs.
- Kept Junior Golf Clubs as an additional player-segment entry.
- Updated the product catalogue filters, category cards, product record category values, navigation menus, Project Builder and Contact enquiry choices.
- Drivers, Fairway Woods, Hybrids, Irons, Wedges, Putters, Complete Golf Club Sets and Junior Golf Clubs each filter to the matching existing product record.
- Park Golf Clubs has a dedicated category landing/empty state and enquiry entry. No Park Golf model, specification or product record was invented.
- Existing product detail galleries and WhatsApp links were not changed.
- Local development only. No GitHub Pages deployment or push.
