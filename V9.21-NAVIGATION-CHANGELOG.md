# V9.21 Mega Menu Refinement

## Design reference
The desktop mega menu follows the user's supplied screenshot:
- Deep navy, wide panel opening directly beneath the header
- Left-side section introduction and browse link
- Two central link columns with gold micro-headings and subtle divider rules
- Right-side rounded project CTA card
- Fine gold accents, restrained shadows and rounded lower corners

## Navigation groups
- Golf Clubs: complete club category links, configurator and custom development
- Partnerships: partnership models, RFQ and project planning
- Manufacturing: engineering, process, materials, finishing, assembly and QC
- Brand & Trust: brand heritage, association / team cooperation, players and events
- Resources: buyer guide, technical notes and tools

## Responsive behavior
- Desktop: hover, click and keyboard-focus open the wide mega menu
- Mobile: retains the two-level drill-down interaction; compact single-column link list
- Menu content and navigation labels support EN / 中文 through the existing bilingual layer

## Scope
This is a navigation-only refinement based on V9.20. Existing page content, product data and imagery are retained.


## V9.21.1 Positioning micro-adjustment
- Replaced fixed left-edge positioning with viewport-centered positioning.
- Desktop menu width is capped at 1180px with balanced 24px side gutters.
- On medium desktop widths, menu uses 16px side gutters.
- Menu remains directly below the header; mobile drill-down positioning is unchanged.


## V9.21.2 Hover persistence fix
- Added a 420ms delayed close when the pointer leaves the navigation trigger.
- Entering the fixed-position mega menu cancels the close timer.
- Leaving the panel schedules the same delayed close, allowing movement back to the navigation.
- Added outside-click and Escape-key close behavior.
- Keyboard focus inside the menu keeps it open.
