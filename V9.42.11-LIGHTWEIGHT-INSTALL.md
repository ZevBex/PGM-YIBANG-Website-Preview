# V9.42.11 Lightweight Update

This package contains only the files needed for the navigation spacing update.

## Install
1. Copy the 23 included HTML files to the website root, replacing the matching HTML files.
2. Copy `assets/css/v9.42.7-navigation-hover-contrast.css` to the same path in the website, replacing the old CSS file.
3. Keep all other folders and files unchanged.
4. After deployment, hard-refresh the browser (`Ctrl + F5`).

The HTML files update the shared navigation stylesheet version to `v9.42.11`, ensuring browsers request the revised CSS.
