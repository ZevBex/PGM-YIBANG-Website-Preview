# V9.32 Media Replacement Register

This register maps every visible placeholder on the website to a stable slot ID. When you send the matching photo, video, drawing or document, the slot can be replaced directly without redesigning the page.

## Recommended source formats
- **16:9 photos:** preferably 1920 × 1080 px or higher; send the original uncropped image.
- **4:5 / 3:4 photos:** preferably 1600 px wide or higher; send the original uncropped image.
- **Engineering drawings / documents:** PDF, PNG or JPG at readable resolution. Remove customer-confidential details before public use.
- **Videos:** MP4, 1080p preferred, or a stable official video URL. Include an approved cover image where possible.
- **Rights:** confirm permission to publish customer logos, player portraits, event photos, certificates and partner-factory footage.
- **Production accuracy:** distinguish in-house R&D / assembly / QC from processes performed by long-term partner factories.

You can send multiple files together. If convenient, include the slot ID in the filename or message, for example `MFG-ENG-2D-01` or `QC-LOFT-LIE-SW-01`. If you do not know which slot a photo belongs to, send it anyway; it can be sorted after review.
