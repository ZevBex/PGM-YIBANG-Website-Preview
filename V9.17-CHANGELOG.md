# V9.17 — Visual & UX Refinement

## Homepage
- Restored a fuller homepage story: documentary partnership previews, four cooperation routes, interactive club configurator, photo-led manufacturing explorer, three brand ambassadors and two brand films.
- Kept dedicated pages as the canonical source for detailed partnership, manufacturing, player and brand information.

## Navigation
- Replaced the old six-pillar mega-menu layout with simpler category dropdowns.
- Desktop dropdowns are centered beneath their own trigger; the Resources menu is right-aligned to stay within the viewport.
- Mobile navigation is a two-level drill-down: first choose a section, then view only that section's links. The mobile panel itself does not scroll.
- Removed legacy V9.10, V8 and V9.5 menu positioning / overflow rules that were overriding the newer menu and causing left-offset dropdowns and long mobile scrolling.
- Golf Clubs dropdown now includes the complete product taxonomy rather than one featured driver link.

## Manufacturing
- Restored the missing `mfg-page` body class. The V9.16 body normalization had dropped this class, preventing the Manufacturing-specific layout selectors from applying.

## Typography
- Added self-hosted Inter / Inter Display for English interface and headings.
- Added EB Garamond for restrained editorial emphasis.
- Added subsetted Noto Sans SC for Chinese interface and body text.
- Added font license notices; no external font CDN is required.

## Bilingual content
- Expanded Chinese translations for the homepage, factory, market and events, insights, product detail, configurator, CHONG Series, RFQ and contact pages.
- Fixed the Contact form helper note so the inline Project Builder link also switches language.
- Removed the duplicate legacy V7 language script; `i18n.js` is the single language controller.

## Product taxonomy
- Added separate Wedges and Junior Golf Clubs filters.
- Added category-query routing from the Golf Clubs navigation into the matching product filter.
- Removed the isolated featured-driver item from the navigation and footer.

## Code cleanup
- Consolidated dropdown behavior in `navigation-v98.js`.
- Simplified `site-shell.js` to back-to-top behavior only.
- Removed obsolete navigation stylesheets and high-specificity legacy mobile menu rules.
- Renamed V9.16 page-specific CSS classes to V9.17.

## Deployment
- Still a local preview package. No new domain, canonical URLs, sitemap or production deployment are configured.
