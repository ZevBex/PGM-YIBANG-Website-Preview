## Preferred files
- Original JPG, PNG or WebP; avoid screenshots, compressed chat previews and watermarked images.
- 1600 px wide or larger; 4:5 or 1:1 for category cards, 16:9 for wide feature images.
- Keep the actual PGM product design, logo, colors and included components unchanged.
- If one image represents only one model or configuration, provide its exact model code so the page copy can identify it correctly.
- Confirm the images are approved for use on the PGM × YIBANG public website.

Once supplied, replace each slot with the matching real product photography; do not reuse one model image to represent an unrelated category.
